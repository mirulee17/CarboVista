# CarboVista

CarboVista is a web-based Geographic Information System (GIS) developed as a Final Year Project to estimate urban above-ground carbon density (ACD) using Sentinel-2 satellite imagery and machine learning.

## Features

- Interactive AOI selection
- Google Earth Engine integration
- Random Forest carbon estimation
- PDF report generation
- Carbon statistics dashboard

## Technologies

Frontend
- Angular
- Leaflet

Backend
- Flask
- Google Earth Engine
- Scikit-learn
- Pandas
- NumPy
